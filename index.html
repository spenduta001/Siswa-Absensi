Sinkronisasi Database Google Sheets

Cara Meng-Online-kan & Sinkron Antar Perangkat (HP & Laptop):

  1. Pastikan URL Web App Google Apps Script di atas sudah terisi, lalu klik Kirim Semua ke Sheet.
  2. Klik tombol Salin Link Online Tersinkron di bawah dan kirimkan link tersebut ke WhatsApp / perangkat lain (HP petugas piket / laptop guru). Saat link dibuka di perangkat lain, URL database otomatis terikat dan langsung menarik data terbaru.
  3. Untuk hosting permanen, klik Unduh File index.html lalu seret & lepas ke app.netlify.com/drop.

Cara Meng-Online-kan Web App (Gratis & Permanen):

  1. Unduh file aplikasi ini dengan klik tombol Unduh File index.html (Siap Online) di bawah.
  2. Buka app.netlify.com/drop (atau GitHub Pages / Vercel) di browser, lalu seret & lepas file index.html tersebut.
  3. Anda langsung mendapatkan tautan publik (misal https://absensi-smpn2ketapang.netlify.app) yang bisa dibuka bersamaan di HP petugas gerbang, laptop guru, dan HP kepala sekolah dengan sinkronisasi otomatis setiap 12 detik.
